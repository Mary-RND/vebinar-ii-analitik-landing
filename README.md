# Лендинг вебинара «Аналитик»

**Рекламный лендинг продающего бесплатного вебинара** — самостоятельный
маркетинговый проект: сбор регистраций через честную продающую структуру,
скорость загрузки и современный дизайн. Один файл на чистом HTML/CSS/JS
без фреймворков и сборщиков.

**Живая версия:** [restless-hat-0282.mar-petrushina.workers.dev](https://restless-hat-0282.mar-petrushina.workers.dev/)

![Лендинг, полная версия (desktop)](screenshots/desktop-full.png)

---

### О проекте

Страница построена по классической рекламной схеме прогрева:

```
Герой с оффером + обратный отсчёт
   -->
Для кого (боли и задачи ЦА)
   -->
Программа вебинара
   -->
Спикер + факты-кейсы
   -->
FAQ
   -->
Форма регистрации с таймером
   -->
Плавающая CTA-кнопка при прокрутке
```

### Возможности

- Обратный отсчёт до даты старта вебинара (25.09.2026, 19:00 МСК) с автосбросом после истечения.
- Форма «Имя + телефон» с валидацией номера и отправкой заявки на почту через **Web3Forms** (без своего бэкенда).
- Спикер-блок с фото и аккордеоном видео-фактов.
- FAQ-аккордеон с плавной анимацией раскрытия.
- Плавающая CTA-кнопка, появляющаяся при прокрутке.
- Reveal-анимации появления блоков (IntersectionObserver).
- Полностью адаптивная вёрстка (mobile / tablet / desktop).
- Open Graph-разметка и og:image для соцсетей.

### Стек

| | |
|---|---|
| Разметка | HTML5 (семантические блоки, Open Graph) |
| Стили | CSS3: custom properties, grid, flexbox, тёмная тема |
| Логика | JavaScript (vanilla): таймер, валидация, аккордеон, reveal |
| Форма | Web3Forms — приём заявок на email |
| Деплой | Статический хостинг (Cloudflare Workers / Pages, Netlify Drop) |

### Запуск

```bash
# локальный просмотр
python -m http.server 8000
# http://localhost:8000/index.html
```

Для деплоя достаточно выложить один файл `index.html` на любой
статический хостинг. Ключ формы подставляется в `WEB3FORMS_KEY`
(получить бесплатно на web3forms.com).
