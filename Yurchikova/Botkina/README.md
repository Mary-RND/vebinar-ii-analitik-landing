# МНКЦ им. С.П. Боткина — анализ закупок за 2025 год

Комплект документов для отклика на задачу: техническое задание, коммерческое предложение и внутренняя записка по цене.

## Файлы

| Файл | Назначение |
|---|---|
| `TZ_Botkin_2025.md` / `.docx` / `.pdf` | техническое задание для клиента |
| `KP_Botkin_2025.md` / `.docx` / `.pdf` | коммерческое предложение с пакетами и ценой |
| `PRICING_INTERNAL.md` | внутренняя записка: трудозатраты, себестоимость, переговорные границы |
| `_tools/md_to_docx.py` | конвертер Markdown → DOCX (использован для сборки) |
| `_tools/md_to_pdf.py` | сборка PDF через Chromium: A4, таблицы, колонтитулы, нумерация |

## Кратко

- **Объект:** МНКЦ им. С.П. Боткина, 2025 год.
- **Предмет:** закупки без хозяйственных расходов, фармации и услуг.
- **Ключевая методика:** правило 80 % для товарных групп и номенклатуры; полный реестр позиций; страна происхождения; внутренние ценовые бенчмарки.
- **Результат:** PDF-отчёт с таблицами + офлайн-дашборд + Excel + реестр позиций.
- **Рекомендуемая цена:** 320 000 ₽ (пакет «Стандарт»).
- **Срок:** 25–35 рабочих дней.
- **Пакеты:** 220 000 / 320 000 / 390 000 ₽.
- **Не входит:** контрактная детализация, отдельный блок по российским участникам, выводы и рекомендации, сравнение с 2024 годом, внешние бенчмарки, презентация.

## Что заполнить перед отправкой

- Наименование и реквизиты заказчика и исполнителя.
- Номер и дата предложения, срок действия.
- Налоговый статус (НДС / без НДС).
- Контакты.
- Подтвердить, что дашборд обязателен.
- Уточнить, есть ли внутренняя выгрузка из 1С/ERP.

## Сборка DOCX и PDF

```powershell
python _tools\md_to_docx.py
python _tools\md_to_pdf.py
```

`md_to_docx.py` читает `TZ_Botkin_2025.md` и `KP_Botkin_2025.md`, создаёт одноимённые `.docx` с титульной страницей, таблицами, колонтитулами и нумерацией страниц.

`md_to_pdf.py` собирает PDF через Chromium: A4, повторяющиеся шапки таблиц, колонтитулы и номера страниц. Скрипт автоматически находит Chrome или Edge; при необходимости путь можно задать вручную в начале файла. Служебный блок с внутренними заметками в DOCX/PDF не попадает.
