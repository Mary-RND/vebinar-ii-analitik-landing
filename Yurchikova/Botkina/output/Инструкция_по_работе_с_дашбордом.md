# Инструкция по работе с дашбордом

ГБУЗ «ММНКЦ им. С.П. Боткина» ДЗМ — анализ закупок за 2025 год

Приложение Ж к комплекту: отчёт, рабочая книга Excel, дашборд

Дата выгрузки данных: 2026-10-22

---

## 1. Назначение и состав комплекта

Дашборд — статический HTML-файл со встроенными данными. Он открывается двойным
щелчком в браузере, работает без интернета, без сервера и без установки
дополнительных программ. Все графики и таблицы строятся в браузере из данных,
записанных в сам файл.

| Файл | Содержание |
|:---|:---|
| `dashboard.html` | интерактивный дашборд: показатели, графики, таблицы, фильтры, поиск в таблицах, экспорт в Excel и CSV |
| `REPORT_Botkin_2025.pdf` / `.docx` | аналитический отчёт: объёмы, структура, 80 %-наборы, страна, бенчмарки |
| `ММНКЦ_Боткина_2025_аналитика.xlsx` | рабочая книга: реестр позиций, сверка, бенчмарки, методика |
| `Реестр_позиций_Боткина_2025.xlsx` | тот же реестр позиций отдельным файлом XLSX (37 столбцов, автофильтр, закреплённая шапка) |
| `Реестр_позиций_Боткина_2025.csv` | тот же реестр позиций в CSV (UTF-8, разделитель «;») |
| `Методика_и_паспорт_данных.pdf` / `.docx` | методика, паспорт данных, источники и ограничения — отдельным документом |
| `Инструкция_по_работе_с_дашбордом.pdf` / `.docx` | настоящая инструкция |

Данные в дашборде: 3 679 позиций профиля на общую сумму
5 436 685 542,52 ₽; всего в выгрузке 6 275 позиций
(2 306 контрактов и договоров за 2025 год).

## 2. Как открыть дашборд

1. Скопировать файл `dashboard.html` в любую папку на компьютере.
2. Открыть файл двойным щелчком. По умолчанию он откроется в браузере по умолчанию.
3. Проверить, что открылся Chrome, Edge или Firefox актуальной версии.

Если браузер открывает файл как текст, выбрать вручную «Открыть с помощью →
браузер». Интернет, VPN и корпоративные ресурсы не требуются: все данные,
шрифты и библиотека диаграмм встроены в файл.

## 3. Экраны дашборда

| Раздел | Что показывает |
|:---|:---|

| Обзор | структура по видам закупки, способам закупки, динамика по месяцам и кварталам |
| Категории 80 % | Pareto-диаграмма товарных групп с линией 80 %, таблица групп, детализация выбранной группы |
| Номенклатура | Pareto-диаграмма и таблица позиций 80 %-набора, поиск по наименованию |
| Страны | сводка по странам происхождения, Россия и импорт, структура по товарным группам |
| Бенчмарки | внутренние ценовые ориентиры: медиана, разброс min–max, отклонение от медианы, потенциал снижения |
| Ключевая номенклатура | карточки позиций 80 %-набора: объём, закупки, поставщики, цена, страна, месяцы |
| Реестр | полный построчный реестр позиций с сортировкой, поиском по таблице и экспортом в Excel и CSV |
| Методика | правила расчёта, классы достоверности, ограничения и краткая инструкция |

## 4. Фильтры

Фильтры расположены в панели под шапкой. Они применяются **одновременно** ко всем
разделам дашборда: показатели, графики и таблицы пересчитываются по срезу.

| Фильтр | Назначение |
|:---|:---|
| Вид закупки | одна из групп § 6.2 ТЗ: оборудование, расходные материалы, имплантаты, реагенты, мебель и одежда, прочие медицинские товары |
| Товарная группа | уровень L2 классификатора (например, «Перчатки и изделия медицинские из резины») |
| Страна | страна происхождения товара по данным ЕИС |
| Происхождение | Россия и импорт / только Россия / только импорт / страна не указана |
| Поставщик | конкретный поставщик по ИНН |
| Сумма от, ₽ / Сумма до, ₽ | диапазон суммы позиции |
| Поиск | подстрока в наименовании позиции |
| номенклатура 80 % | только строки, относящиеся к номенклатурному 80 %-набору (256 позиций из 1 344) |
| без оценочных | исключить позиции с расчётными суммами |

Под панелью выводятся «чипсы» с активными фильтрами. У каждого чипа есть крестик,
который снимает соответствующий фильтр. Кнопка «Сбросить» очищает все фильтры
одновременно.

Фильтры не меняют учёт: карточки «Профильный объём», «Отсечено фильтрами»,
«Исключено» и «Общий объём 2025» всегда дают проверяемое равенство —
**срез + отсечено фильтрами + исключено = общий объём**.

## 5. Таблицы

Над каждой таблицей — своя строка управления: поле поиска, счётчик показанных строк,
для длинных таблиц выбор числа строк (100 / 300 / всё) и кнопки выгрузки.

- Сортировка — щелчок по заголовку столбца; значок ▲ или ▼ показывает, по какому
  столбцу и в каком направлении идёт сортировка. Повторный щелчок меняет направление.
- Поиск по таблице — поле над таблицей сужает **только эту таблицу** и не меняет
  показатели, графики и остальные разделы; рядом выводится «Показано X из Y строк».
- Итоговые строки — внизу таблиц: сумма и количество по срезу. Когда поиск по таблице
  активен, итог пересчитывается по показанным строкам и подписывается
  «Итого по фильтру таблицы».
- Экспорт одной таблицы — кнопки «Excel» и «CSV» в её строке управления. Выгружаются
  ровно те строки, что видны на экране после фильтров и сортировки.
- Экспорт всего отчёта — кнопка «Excel — весь отчёт» в верхней панели: один файл
  .xlsx с листами «Описание», «Показатели», «Категории», «Номенклатура»,
  «Бенчмарки», «Страны» и «Реестр» по текущему срезу. Каждый лист начинается с
  названия, даты выгрузки и источника; шапка закреплена, автофильтр включён, числа
  остаются числами, поэтому из файла можно строить сводные таблицы.
- Выгрузка реестра в CSV — кнопка «CSV — реестр» в верхней панели: разделитель «;»,
  кодировка UTF-8 с BOM, файл открывается в Excel без настройки.
- Реестр позиций подгружается по мере прокрутки; в печать выводится полностью.

## 7. Темы и печать

Кнопка «Тема» переключает светлую, тёмную и системную тему без перезагрузки страницы.
Кнопка «Печать / PDF» открывает диалог печати браузера: в настройках нужно выбрать
формат A4, ориентацию «альбомная» для широких таблиц и включить «фоновую графику».
Печать всегда выполняется в светлой теме, с повтором шапок таблиц на каждой странице.

## 8. Факт и оценка

- **Факт** — сумма позиции опубликована в ЕИС.
- **Оценка** — контракт не содержит сумм позиций (или количества), поэтому сумма
  распределена по цене контракта пропорционально цене за единицу. Такие позиции
  помечены словом «оценка» и составляют 45,7 % профиля.
  Фильтр «без оценочных» убирает их из среза.

## 9. Ограничения и правила интерпретации

1. Дашборд носит описательный характер: выводов и рекомендаций он не содержит.
2. Страна происхождения — по полю «Страна происхождения» в спецификации ЕИС; по
   стране поставщика она не подставляется. Определено 92,2 %
   стоимости профильных закупок.
3. Бенчмарки — внутренние, рассчитаны только по закупкам учреждения за 2025 год;
   внешние прайсы и данные других учреждений не используются.
4. Правило 80 % — все группы и позиции до накопленной доли 80 % профильного объёма
   включительно; наборы категорий (8 из 26) и номенклатуры
   (256 из 1 344) рассчитаны независимо.
5. Потенциал снижения — оценочная величина, а не гарантия экономии.
6. Сравнение с другими учреждениями и с другими годами в дашборд не входит.
7. Дашборд не содержит реквизитов контрактов и сведений о конкретных закупках —
   только обезличенные позиции реестра.

## 10. Возможные вопросы

**Дашборд открылся без графиков.** Проверьте, что файл сохранён целиком и имеет
расширение `.html`, а не `.html.txt`. При переименовании сохраняйте расширение.

**Фильтры не применяются.** Проверьте значения во всех полях панели: выбранный
диапазон суммы или текст поиска могут исключать большую часть среза. Кнопка
«Сбросить» возвращает исходное состояние.

**В выгрузке нет всех строк.** Экспортируется текущий отображаемый срез: в Excel и CSV
попадают те строки, что видны в таблице после фильтров. Для полного списка сбросьте
фильтры кнопкой «Сбросить», в поле «Показать» над таблицей выберите «все строки» и
повторите экспорт. Полный построчный реестр среза всегда есть на листе «Реестр» файла
«Excel — весь отчёт».

**Печать обрезает таблицы.** В диалоге печати включите «фоновую графику» и выберите
альбомную ориентацию; для печати реестра используйте масштаб 60–70 %.

**Расхождение с отчётом.** Проверьте, что открыт файл той же выгрузки: дата выгрузки
указана в шапке дашборда и в паспорте данных (приложение В) отчёта.
