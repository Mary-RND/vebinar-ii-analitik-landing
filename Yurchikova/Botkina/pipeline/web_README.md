# Дашборд закупок МНКЦ им. С.П. Боткина — 2025

Публичная страница дашборда с доступом по паролю. Страница размещена на GitVerse Pages.

- **index.html** — страница входа: поле пароля и кнопка «Открыть».
- **payload.bin** — сам дашборд в зашифрованном виде.

## Как устроен доступ

Дашборд зашифрован алгоритмом **AES-256-GCM**. Ключ выводится из пароля методом
**PBKDF2-HMAC-SHA-256** (250 000 итераций, случайная соль в 16 байт на каждой сборке).
Пароль в файлы не попадает: расшифровка происходит в браузере посетителя.

Поэтому:

- репозиторий и страница могут быть публичными — без пароля данные не читаются;
- при смене пароля дашборд нужно пересобрать (шифротекст старого пароля бесполезен);
- тот, кто знает пароль, может открыть дашборд, сохранить его локально или распечатать.

## Как пересобрать и опубликовать заново

На рабочей машине в каталоге проекта:

```
python pipeline/build_web.py --password "новый пароль"
```

Скрипт читает собранный `output/dashboard.html` и пишет новую пару `index.html` + `payload.bin`
в `output/web/`, обновляет этот README и делает коммит в репозиторий сайта.

## Как публикуется сайт

В репозитории настроен CI/CD workflow `.gitverse/workflows/publish-pages.yml`: он
копирует `index.html` и `payload.bin` в артефакт и публикует сайт как есть, без сборщика.

Резервный вариант — встроенный режим GitVerse Pages: **Настройки → Страницы → источник
«Ветка» → `main` → `/`** (сборка через Jekyll при каждом коммите).

## Что внутри дашборда

- 9 разделов: показатели, структура и динамика, категории 80 %, номенклатура, страны,
  бенчмарки, ключевые позиции, построчный реестр, методика;
- фильтры по виду закупки, товарной группе, стране, происхождению, поставщику,
  диапазону суммы и поиску по наименованию;
- в каждой таблице: поиск по этой таблице, сортировка по столбцу, выбор числа строк
  и выгрузка показанных строк в Excel или CSV;
- кнопка «Excel — весь отчёт» — один файл .xlsx на 7 листов по текущему срезу;
- светлая, тёмная и системная темы, кнопка «Печать / PDF»;
- все данные встроены в страницу, внешних запросов и CDN нет.

Данные — из открытых реестров ЕИС (44-ФЗ и 223-ФЗ), выгрузка от __BUILT__.

## Ограничения

- Оценочные значения (45,7 % профильных позиций) помечены словом «оценка» и не
  предназначены для официальной отчётности.
- Поставщик по договорам 223-ФЗ в ЕИС не публикуется, для таких позиций указано
  «не указан в ЕИС (реестр 223-ФЗ)».
- Полный комплект документов (отчёт PDF/DOCX, рабочая книга Excel, реестр позиций,
  методика и паспорт данных, инструкция) передаётся отдельным архивом, а не здесь.
